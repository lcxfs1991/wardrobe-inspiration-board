# 展示层输出契约

## 适用与触发

用户要求把灵感结果可视化、要做成网页或图片看板、要一份能单独发送或离线打开的文件时读取本文件；运行宿主具备网页呈现能力、且用户需要把结果带走查看时同样适用。

只在灵感生成流程输出完成、生成记录写入完成后执行本契约；展示层只读取档案与本次记录，不改写 `wardrobe.md`、`outfit.md`、`profile.md`、`inspiration-log.md`，不删除或改动原图。

运行宿主不具备生成网页文件的能力时，只输出 Markdown 清单并如实说明该能力不可用，不声称已输出网页，也不用图片引用伪装成可视化。

本文件只描述契约，不携带脚本、样式或二进制资源；Skill 包内只允许入口文件与 Markdown 参考文档。

## 输出物形态

- 产物是一个文件，默认文件名 `wardrobe-board.html`，写入用户真实数据目录；文件名与目录由文件专家确认或准备。
- 单文件自包含：不引用外部样式表、脚本、字体、图标库或网络资源。
- 桌面端与移动端**共用同一份产物**，不按设备分叉、不额外产出「移动版」「精简版」。
- 图片一律以 base64 内嵌，桌面端也只用内嵌图片：不因打开设备不同而切换引用方式。
- 每条图片标签直接写内嵌数据，不靠脚本去重或延迟注入；部分移动端与聊天软件的预览器不执行脚本，图片显示不能依赖脚本运行。

## 页面范围：只含本次推荐结果

必须包含：

| 区块 | 内容 |
| --- | --- |
| 抬头 | 标题、当前用户姓名、生成时间 |
| 基本信息 | 姓名、颜色偏好与风格偏好的概要（非敏感项） |
| 本次情景 | 场景、目的地、时间、天气或温度，各一项 |
| 单品搭配 | 最多三种，每套含组成单品的图片、单品名称、风格、颜色、适合季节与取舍理由 |
| 过往照片引用 | 最多三种，每张含图片、描述、来源标注、适合季节与场景 |
| 说明 | 数据来源、图片已内嵌、天气只采用用户文本、未引入资料外商品与趋势 |

不得包含：

- 衣橱全量单品图册，以及按类别分组的全量单品列表。
- 过往穿搭全量图册，以及按场景分组的全量穿搭列表。
- 面向全量档案的筛选器、分类下拉、季节切换与「显示 N / 总数」计数。
- 全量档案规模统计（如「共 42 件单品、24 套穿搭」）；只允许「本次引用的单品数与照片数」这类本次范围计数。

理由：展示层是推荐结果的呈现，不是档案浏览器；把全量图册搬上来会让页面体积与信息量一起失控，也把用户的注意力从「这次穿什么」拉走。要看全量档案，读 Markdown 档案即可。

## 图片处理

| 项 | 取值 |
| --- | --- |
| 缩放 | 长边 640px，等比缩放，足够覆盖移动端 3 倍屏的卡片尺寸 |
| 格式 | 渐进式 JPEG，quality 80 |
| 透明通道 | 先合成到白底再转 JPEG，否则透明区会变黑 |
| 原图 | 只读，不缩放、不覆盖、不移动、不删除 |
| 内嵌 | `data:image/jpeg;base64,` 前缀加编码结果 |

体积控制：单个产物目标不超过 8 MB。超出时先降一档（长边 480px、quality 78）并如实说明降质；仍超出时减少引用的照片数量并说明删减了哪几张，不把一份结果拆成多个文件。

同一张图片被多处引用时允许重复内嵌，用体积换「不依赖脚本」；不为了省体积改成脚本字典注入。

## 内容与合规

- 性别、出生年月、身高（cm）、体重（kg）、身形、肤色、常驻生活城市与常驻工作城市等敏感字段不进页面，连字段名都不出现。
- 页面事实只来自档案真实文本与本次生成记录；不引入未检索到的趋势、商品、购买链接或天气推测。
- 天气或温度只采用用户本轮给出的真实文本；未提供时写「未提供」，不留空、不推测。
- 全中文表述；不生成英文对照。
- 页面不写主机绝对路径与数据根目录：这类是运行时真实值，写死会在换设备、换用户、换目录时失效，也属路径泄漏。图片已内嵌，说明「图片已内嵌，可离线查看」即可。

## 校验

产物写入后按下列项核对，任一项不通过都不声明展示层完成：

1. 所有图片标签的来源都以 `data:image/jpeg;base64,` 开头；不存在相对路径、绝对路径、`file://` 或 `http` 图片地址。
2. 页面不存在外部样式表、外部脚本、字体或 CSS `url()` 外链。
3. 每个内嵌数据都能 Base64 解码，且以 JPEG 起始标记开头、结束标记结尾。
4. 结构标签开闭平衡；页面不含全量图册区块与全量档案规模统计。
5. 敏感字段名与值零残留。
6. 把该文件单独复制到一个不含任何图片的空目录后打开，图片仍能显示。

## 失败与降级

- 宿主无网页能力：退回 Markdown 清单，如实说明展示层未生成。
- 某张图片读不到或解码失败：如实说明是哪几条引用失败，其余照常呈现，不拿相似图片替代，不伪造内嵌数据。
- 写入被拒绝或审批未通过：不声明展示层已生成。
- 任何情况下都不把「已写入文件」说成「已在目标设备打开正常」；真机打开效果需用户实际打开后才能确认。
