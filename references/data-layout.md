# 数据布局与索引约定

## 存放边界

Skill 包内只保存流程说明与静态字段模板，不保存任何用户数据。所有运行时数据写入 NAS 上由用户指定的真实根目录，由文件专家读写。同一份 Skill 换用户、换设备或换根目录即可复用，不需要修改包内内容。

## 索引文件

索引文件名统一为 `index.md`，位于用户指定的 NAS 根目录，记录姓名与真实数据目录的对应关系，以及最近使用用户。字段结构：

| 字段 | 说明 |
| --- | --- |
| 用户姓名 | 用户本轮指定或由最近使用用户字段解析出的真实姓名 |
| 真实数据目录 | 索引读取完成后返回的真实目录，不猜测个人路径 |
| 最近使用用户 | 最近一次成功解析并使用的真实姓名 |
| 更新时间 | 运行时真实时间，不使用推测日期 |

未初始化判定只依据索引文件的真实文本，不依赖上下文记忆、目录外观或文件修改时间：

| 索引读取的真实结果 | 判定 | 下一步 |
| --- | --- | --- |
| `index.md` 不存在或读取为空 | 尚未初始化 | 执行首次使用初始化引导 |
| `index.md` 无任何用户条目 | 尚未初始化 | 执行首次使用初始化引导 |
| 有用户条目，最近使用用户缺失、为空或无法解析 | 已初始化但未选中用户 | 跳过引导，向用户询问姓名 |
| 有用户条目，最近使用用户可解析 | 已初始化 | 跳过引导，直接走公共前置 |
| 用户指定的姓名不在索引中 | 新增用户 | 执行引导中的新增用户分支，不静默回退 |

约束：

- 索引文件不存在、为空或没有任何用户条目时，先执行首次使用初始化引导创建 `index.md` 与可选的 `profile.md`；引导写入全部完成后才允许进入任何业务流程。
- 索引读取完成且返回真实姓名与真实目录后，才能读取该目录下的资料文件。
- 指定的姓名在索引中不存在时向用户询问其数据目录，不静默回退到最近使用用户。
- 最近使用用户缺失、为空或无法解析时向用户询问，不硬编码默认用户。
- 更新索引只修改本次涉及的条目，保留其余条目，不覆盖历史记录；写入有审批要求，等待审批不算完成。
- 索引文件不是授权来源，也不代表知识索引可用。

## 数据文件

| 文件 | 内容 | 写入时机 |
| --- | --- | --- |
| wardrobe.md | 衣橱单品的中文字段 | 衣橱建档流程完成后 |
| outfit.md | 过往穿搭的中文字段与来源标注 | 搭配记录流程完成后 |
| profile.md | 性别、出生年月、常驻生活与工作城市、颜色与风格偏好、身高（cm）、体重（kg）、肤色、身形 | 个人资料流程完成后 |
| inspiration-log.md | 每次灵感生成的记录与用户采纳结果 | 灵感输出完成后、用户明确采纳后 |

四个文件都位于索引返回的真实目录下。文件名是稳定约定，目录是运行时真实值。

首次使用初始化引导阶段只创建 `index.md` 与（用户给出个人资料时的）`profile.md`；`wardrobe.md`、`outfit.md`、`inspiration-log.md` 不预建，保持「档案不存在或读取为空即首次建档」的增量差集语义，以及「采纳关联来自记录文件真实最后一条」的语义。

## 字段模板

所有字段与字段值统一只用中文记录，不生成英文对照、不翻译用户给出的原文；用户原文中的外文专名按原文保留。已有历史记录保持原样，不改写、不删除其中的英文字段；后续追加记录只用中文。

### 衣橱单品

| 字段 | 值（中文） | 来源 |
| --- | --- | --- |
| 图片真实路径 | 真实路径 | 文件专家返回的真实结果 |
| 单品名称 | 必填 | 视觉问答真实返回，只记录衣物单品 |
| 风格 | 必填 | 视觉问答真实返回 |
| 颜色 | 必填 | 视觉问答真实返回 |
| 适合季节 | 必填 | 视觉问答真实返回 |

### 过往穿搭

| 字段 | 值（中文） | 来源 |
| --- | --- | --- |
| 图片真实路径 | 真实路径 | NAS 内真实路径 |
| 来源标注 | 必填 | 本地拍摄或网络下载，由用户给出 |
| 风格 | 必填 | 视觉问答真实返回 |
| 颜色 | 必填 | 视觉问答真实返回 |
| 适合季节 | 必填 | 视觉问答真实返回 |
| 场景 | 必填 | 视觉问答或用户补全 |

字段不全时向用户补问，不编造、不留推测值。

### 个人资料

全部字段只用中文记录；cm 与 kg 只作计量单位标注，不生成英文对照。字段如下，用户未给出的字段保持空缺并如实说明，不推测、不补写：

| 字段 | 层级 | 值（中文） | 来源与约束 |
| --- | --- | --- | --- |
| 性别 | 建议 | 用户自述 | 只记录用户明确给出的值，不从姓名、照片或措辞推断 |
| 出生年月 | 建议 | `YYYY-MM-dd` 或用户原文 | 用户给出完整年月日时按 `YYYY-MM-dd` 记录并把月与日补零，只改写法、不改日期语义；只给年月、年龄段、农历或非标准日期时按原文保留并如实说明，不补写日或年份、不换算农历、不推算年龄、不按日期推断风格 |
| 常驻生活城市 | 建议 | 用户给出 | 城市名按原文记录，不由姓名或目录推断 |
| 常驻工作城市 | 建议 | 用户给出 | 同上；点选「与生活城市相同」时复制用户本轮给出的生活城市真实文本 |
| 颜色偏好 | 可选 | 用户给出 | 非敏感偏好，按原文记录，不给默认值 |
| 风格偏好 | 可选 | 用户给出 | 非敏感偏好，按原文记录，不给默认值 |
| 身高（cm） | 建议 | 用户给出 | 按 cm 记录数值；只给数值时按标注单位记录并如实说明，给出其他单位时保留原值与原单位、不换算 |
| 体重（kg） | 建议 | 用户给出 | 按 kg 记录数值，规则同身高 |
| 肤色 | 可选 | 用户点选的词表值或手动输入原文 | 可点词表为白皙、自然、小麦、蜜色、深色；词表只作候选并须列全，不由其他字段推断，不预填、不默认选中；词表外说法按原文记录 |
| 身形 | 可选 | 用户点选的词表值或手动输入原文 | 可点词表为苹果型、梨型、沙漏型、直筒型、倒三角型、匀称型；词表只作候选并须列全，不由其他字段推断，不预填、不默认选中；词表外说法按原文记录 |

字段名「出生年月」沿用用户说法，值按 `YYYY-MM-dd` 记录时含日；`YYYY-MM-dd` 是数字日期格式约定，不属于英文对照或翻译。

性别、出生年月、身高（cm）、体重（kg）、身形、肤色、常驻生活城市与常驻工作城市属敏感个人信息，只在 profile.md 内使用；它们可作为搭配取舍的内部约束，但不在灵感输出或生成记录中逐项扩散，不写入其他文件。颜色偏好与风格偏好属非敏感偏好，可在「用户基本信息」中作概要回显。

### 生成与采纳记录

每条生成记录包含：记录标识、运行时真实时间、用户指令原文、情景字段、输出的最多三种单品搭配、引用的真实照片路径。记录标识来自写入后返回的真实业务值，供采纳记录关联使用。

采纳记录包含：所关联的记录标识、采纳序号或都不采纳、用户原话。只在用户明确表达时写入。

## 增量建档与重新识别

衣橱建档与搭配记录都支持对同一目录或同一范围二次索引，判定依据只有档案文件的真实内容，不依赖上下文记忆、文件修改时间或目录外观，也不新增独立的图片索引文件。

| 项目 | 约定 |
| --- | --- |
| 已索引范围 | `wardrobe.md` / `outfit.md` 中「图片真实路径」字段的真实值，由文件专家读取档案真实文本后取得 |
| 首次建档 | 档案不存在或读取为空，本轮全部真实图片路径都算新增 |
| 二次索引 | 只对本轮真实路径与已索引路径的差集发起视觉问答，逐项精确比对，不模糊匹配、不按相似度排除 |
| 无新增 | 如实报告「没有新增照片」并停止，不发起视觉识别、不追加写入、不产生空写入审批 |
| 档案无法解析 | 不推断已索引范围，如实报告并停止，由用户决定修复档案或明确要求重新识别 |
| 重新识别 | 仅用户明确说出重新识别、全量重新索引或重扫时触发，对全部真实路径做视觉问答；触发语不靠推断 |
| 全量重建 | 仅用户明确说出重新构建、全量重建、旧数据全部清理后重做时触发；旧记录全部清除，档案只保留本轮识别结果，执行前必须记录旧条数并备份，写入后通过四项校验，详见重建模式文档 |
| 历史数据 | 已删除的照片不从档案中移除；重新识别结果按原有字段追加，旧记录保留、不覆盖不删除 |

重新识别后，同一真实路径可能在档案中出现多条记录；读取与整理时以该路径的最后一条记录为准，避免重复单品或重复搭配。所有写入仍遵循追加、不覆盖、不删除历史、不删除或改动原图，且都有审批要求。

全量重建是唯一会清除历史记录的写入：只清除用户确认的那一个档案文件（`wardrobe.md` 或 `outfit.md`），清除前原样另存为同目录的时间戳备份；索引文件、`profile.md`、灵感与采纳记录、原图一律不动。除该模式外，任何写入都不得覆盖或删除历史记录。

## 读写约束

- 所有写入由文件专家完成，追加写入，不覆盖、不删除历史记录、不删除或改动原图；唯一例外是用户明确要求的全量重建，此时先备份再覆盖单一档案文件。
- 写入有审批要求；自然语言同意不能代替平台审批，等待审批不算完成。首次使用初始化引导的写入同样有审批要求，引导未全部完成时不得进入后续流程，也不得声明整体完成。
- 初始化已完成索引写入（含最近使用用户与运行时真实时间）时，公共前置不重复发起等价写入委托，避免重复审批。
- 保存成功不等于知识索引可用；已知 Markdown 路径直接交给负责专家读取，不走知识搜索索引。
- 跨轮次查找最近一次生成记录时，读取记录文件的真实最后一条；不依赖上下文记忆，不猜测记录标识。
